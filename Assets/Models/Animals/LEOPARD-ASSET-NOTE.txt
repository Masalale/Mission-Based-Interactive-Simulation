LEOPARD ASSET NOTE
==================

There is no CC0 leopard model in this project. The Leopard animal is a
documented re-skin, per BUILD-SPEC section 7 ("Leopard" fallback):

  Mesh   : Assets/Models/Animals/SM_Lion.fbx  (Grab3D, CC0)
            reused at 0.7 scale
  Coat   : Assets/Models/Animals/Textures/T_LeopardCoat.png
            procedurally generated rosette pattern, not a third-party asset
  Material: Assets/Materials/M_Leopard.mat  (URP Lit, base map = coat,
            smoothness 0.25, tiling 3x3)

Do not describe the Leopard as a hand-made or a CC0 leopard model. In the
project README it must be disclosed as a re-skin of the lion mesh wearing a
procedurally generated coat.

Swapping in a real leopard model later: drop the new mesh into
Assets/Models/Animals/, point the PF_Animal_Leopard variant at it, and keep
M_Leopard.mat if a spotted look is wanted. Nothing else depends on the mesh.
